分類與 Tag 讓讀者找到相關主題，分頁控制列表長度，搜尋則適合已經知道關鍵字的讀者。 SEO 設定管理搜尋與分享資訊。本篇把這些入口串成完整流程，同時展示表格、有序清單， 以及仍可公開閱讀的 noindex 文章。

首次建站可先用這篇檢查共用版型的表格與清單；日常則從 Studio 調整分類、Tag 與 SEO。 不論原生環境或 Docker，都可以使用相同介面，也可在 IDE 模式由編輯器或 AI 依資料格式修改。

先決定分類，再選擇需要的 Tag

每篇文章只有一個分類，可以設定零個或多個 Tag。本網站以「筆記」整理啟動、圖片與搜尋的指南， 以「工具」整理影片及維護操作；「範例」、「工作流程」、「媒體」則用來串起跨分類的主題。

  1. 在 Studio 的「分類與 Tag」建立需要的項目，或點擊既有項目修改名稱與描述。
  2. 回到文章設定，選擇一個分類，再依內容選擇適當 Tag。
  3. 保存文章並更新網站，點文章上的分類或 Tag，確認能找到相關內容。

如果只想把顯示名稱改得清楚，直接編輯名稱即可。只有要改變連結中的網址名稱時， 才使用「修改分類或 Tag 網址」：選項目、填新網址名稱、查看變更影響，再確認變更。 系統會同步受影響的文章屬性、子分類及導覽；正文原有的連結仍需要由作者修正，也不會自動建立轉址。

實際查看分頁與搜尋

本 release 的分類、Tag 及文章總覽每頁顯示兩篇文章。 「筆記」有三篇，因此 筆記分類會有兩頁； 「工具」有兩篇，工具分類目前是一頁。 五篇文章的總覽可從 文章總覽查看並換頁。

  1. 先開啟筆記分類，點「下一頁」，確認頁面仍顯示相同分類，文章內容已換成後續項目。
  2. 回到文章總覽，在「關鍵字」輸入「圖片」並搜尋，查看相關文章。
  3. 嘗試輸入分類、Tag 或摘要中的文字，再清空關鍵字查看全部文章。
  4. 使用瀏覽器上一頁與下一頁，確認能返回剛才的搜尋狀態。

搜尋使用公開搜尋資料，需要瀏覽器 JavaScript。文章本身及分類頁的主要內容都已在完整 HTML 中， 即使沒有啟用搜尋互動，讀者仍可透過導覽與分類連結閱讀文章。新增文章後須成功更新網站， 新內容才會加入 4322 使用的搜尋資料。

依序檢查發布資訊

  1. 確認分類、網址名稱及 Tag 能清楚表示文章主題。
  2. 撰寫文章自己的 Meta Description，核對 SEO Title 與分享圖片的實際預設值。
  3. 依內容決定 Indexing，確認日期、連結、章節與媒體皆有效。
  4. 保存並更新網站，在 4322 查看文章、分類、搜尋及網頁原始碼。

公開網站會產生哪些資訊

網站依保存的設定產生 title、description、canonical、robots、Open Graph、Twitter Card 及適用的結構化資料。 文章頁還包含文章與麵包屑資訊。這些內容由共用規則產生，新增文章不需要逐篇編輯網頁 head。

你也可以查看 RSS、Sitemap 索引 與 robots.txt。Sitemap 索引再指向實際網址清單， 正式網站網址由全站設定決定；這個通用範例保留 https://example.invalid/，使用者應在公開前換成自己的網址。

常見問題

改了分類名稱，連結會一起改嗎？
顯示名稱與網址名稱各自設定。只有明確變更網址名稱時，公開 URL 才會改變；完成後檢查正文連結並更新網站。
為什麼這篇 noindex 文章還搜得到？
站內搜尋使用網站自己的公開文章資料。noindex 控制搜尋引擎索引意願，不會把已發布文章從站內搜尋或 RSS 移除。
搜尋沒有結果，或沒有出現新增文章？
先確認文章已發布、網站更新成功，搜尋文字也確實出現在標題、分類、Tag 或摘要中；再依畫面的搜尋載入提示重試。
把文章改成草稿後，4322 還能開啟？
撤回保存後還要成功更新網站，既有公開頁面才會移除；工作失敗時保留舊網站。

最後閱讀 固定頁面、文章版型與 IDE 維護， 或到 工作流程標籤查看相關指南。

組合搜尋、分類與 Tag

文章總覽可同時填入關鍵字並勾選分類與 Tag。關鍵字先正規化為小寫，再依空格分詞，符合任一詞即可；命中較多詞的文章優先。同一組分類或 Tag 符合其中一項即可，不同組之間則需同時符合。

試著在文章總覽輸入「圖片 影片」，勾選媒體 Tag，再切換分類或翻頁。網址會保留條件，瀏覽器返回與前進也會恢復對應結果。分類與 Tag 的總覽提供描述、文章數及各主題入口。

逐欄理解八種頁型 SEO

全站設定可分別調整首頁、文章、文章總覽／搜尋、分類總覽、分類頁、Tag 總覽、Tag 頁及 404。每個欄位依單筆覆寫、頁型設定、全域設定的順序判斷；只改某一欄，不會讓其他欄一起停止繼承。

Indexing 為 Noindex 時仍可公開閱讀。零篇文章的分類或 Tag，以及 404、草稿預覽等情境另有固定的索引規則，請以介面說明與實際成功網站輸出一起確認。
